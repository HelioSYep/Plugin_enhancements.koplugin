# 插件增强

`Plugin_enhancements.koplugin` 是一个统一管理 KOReader 功能补丁和
SimpleUI 扩展模块的插件。

当前正式版本为 `1.1.4`，保留项目已有的全部功能，并完成对 SimpleUI
2.6.0（包括 2.6.0 标签之后的屏幕旋转、书籍模块滑动与局部刷新修复）的适配。
当前版本同时兼容 SimpleUI 2.1.1、2.5.0 与 2.6.x。插件会自动探测旧版
`desktop_modules/ + sui_*.lua` 和新版 `modules/ + infra/ + screens/`
目录结构，不需要手动选择版本。

1.1.4 在保留 1.1.3 渲染修复的同时，恢复扩展模块原有的固定字体与组件颜色。
SimpleUI 2.6 不再映射到新语义色表，因此不会改变旧版视觉灰阶；SimpleUI
2.5 仍会使用其原有的可配置主题颜色接口。

1.1.3 修复 SimpleUI 2.6.0 移除 `SUIStyle.getThemeColor()` 后，Hero、With
Pace、Yanllsama Legacy、最近阅读统计以及封面轮播简介在构建阶段报错并被
主屏幕静默跳过的问题；统一通过兼容层读取 2.5 的动态主题颜色或 2.6 的
`SUIStyle.COLOR` 语义颜色。扩展模块注册后也会主动重建已打开的 SimpleUI
布局，避免启动顺序留下旧的模块缓存。

1.1.2 以桌面目录 `simpleUI v2.6.0`（2026-08-28）为当前 2.6 基线重新
验证。该版本相对上一份快照修改了中文翻译、时钟日期、阅读目标月份、热力图
日期范围和统计窗口日期。现有注册表、Quick Action、书籍缓存、壁纸、自定义
屏幕及刷新接口保持兼容；时钟中文日期补丁已适配其原生中文月日格式，移除
逐次重绘警告日志，并在热修复失败时向插件菜单返回明确错误。

1.1.1 在 1.1.0 兼容层之上修复两类冲突：模块副本不再二次复制 SimpleUI
原生动态实例（快捷操作行、间隔行和精选书架行）；主页屏保与阅读分析屏保
改用单一共享分发器，不再分别嵌套包装全局 `require`、`dofile` 和
`Screensaver.show`。

1.1.0 的兼容调整包括：识别 2.6 独立壁纸与 Quick Action 渲染组件；主页
屏保使用新版壁纸接口和完整模块上下文；最近阅读多行正确处理 2.5+/2.6 的
`sui_book_grid` 行缓存；返回阅读器后刷新所有活动的自定义屏幕；双状态图标
保留 2.6 动作条目的状态元数据。

组件文件会在 KOReader 启动时加载，以便读取名称、说明和设置菜单；新发现的
模块和补丁初始状态全部为关闭：

- 模块关闭时不会注册到 SimpleUI。
- 补丁关闭时不会执行 `apply()`。
- 在“插件增强”中更改状态后，需要完整重启 KOReader。
- 已经保存过的用户选择不会被版本升级重置。

## 扩展模块

| 模块 | 功能 |
|---|---|
| 当前阅读 (With Pace) | 带有每日速度、页速和进度速度的当前阅读卡片 |
| 当前阅读 (Yanllsama Legacy) | 可配置网格、统计项目、字体和进度条的旧版阅读面板 |
| 当前阅读 (Hero) | 大型当前阅读卡片，包含封面、进度、简介和统计 |
| 阅读统计 | 年度阅读统计和月度图表 |
| 阅读连胜 | 当前及最佳连续阅读天数、周数 |
| 最近阅读统计 | 最近阅读书籍的进度、时间和统计卡片 |

模块启用后，其详细外观和内容设置位于：

```text
SimpleUI 首页 → 排列模块 → 对应模块
```

## SimpleUI 补丁

| 补丁 | 功能 |
|---|---|
| 前光灯：滑块样式 | 为前光灯和色温提供原版、细线、圆形三种滑块样式 |
| 快捷设置栏：双状态图标（长按进入设置） | 为已绑定且能读取状态的插件或系统快捷动作分别选择开启、关闭图标；执行后保持快捷设置栏开启并实时刷新状态图标（兼容 SimpleUI 2.5.0/2.6.x 的共享渲染器） |
| 最近书籍模块：增加行数和排除路径功能 | 最近书籍多行布局、行距、路径排除及忽略第一本书 |
| 封面轮播模块：增加排除路径功能 | 从封面书架最近书籍来源中排除指定路径 |
| 封面轮播模块：增加书籍简介显示 | 在封面书架上方或下方显示活动书籍简介 |
| 模块副本功能 | 允许单例模块生成多个副本并放在不同首页页面；快捷操作行、间隔行和精选书架行继续使用 SimpleUI 原生的独立实例功能；2.5.0/2.6.x 同时识别并刷新自定义屏幕布局 |
| 时钟模块：中文日期格式支持 | 将 SimpleUI 时钟日期改为“2025年 6月3日 星期三”格式；兼容桌面 2.6 版原生中文月日输出 |
| 新增屏保：主页屏保 | 将指定或随机 SimpleUI 首页显示为休眠屏 |
| 新增屏保：阅读分析屏保 | 将指定或随机阅读洞察页面显示为休眠屏 |

启用补丁并重启后，具体配置会进入其实际影响的位置，例如：

```text
SimpleUI → 快捷设置栏 → 滑块样式
SimpleUI → 排列模块 → 最近书籍
SimpleUI → 排列模块 → Cover Deck
设置 → 屏幕 → 休眠屏 → 壁纸
```

### 快捷设置栏双状态图标

启用“快捷设置栏：双状态图标（长按进入设置）”并重启 KOReader 后，在该补丁菜单项
上长按进入设置。设置页只列出已经在 SimpleUI 中绑定的插件或系统快捷动作：

```text
插件增强 → SimpleUI → 功能补丁
└── 快捷设置栏：双状态图标（长按进入设置）
    ├── 短按：启用或关闭补丁
    └── 长按：进入双状态图标设置
```

图片继续放在 SimpleUI 原有目录 `koreader/settings/simpleui/sui_icons/`，支持
SVG、PNG 和 Nerd Font 图标，文件名可以任意。开启图标与关闭图标均通过
SimpleUI 自带的 Kindle 图标选择器选取，不会覆盖 SimpleUI 原有的单图标。

当前状态识别规则：

- 插件动作必须已经绑定为 SimpleUI 自定义快捷动作。
- 插件提供 `isRunning()`、`isEnabled()`、`isActive()`、`isOpen()` 或主菜单
  `checked_func` 时可以设置双状态图标。
- 只有 `launch`、没有状态接口的插件会显示为“仅单图标”。
- 系统操作识别 FileBrowserPlus 服务、Wi-Fi、前光灯、夜间模式、重力感应、
  自动旋转锁定、角落长按、触摸输入、实体翻页键反转、按键重复、电子墨水屏
  闪屏设置、点击链接、翻页动画以及横屏/竖屏。
- 设备专属操作会先检查当前设备能力；设备不支持、状态接口不可用或从其他
  设备迁移来的无效绑定会自动退回 SimpleUI 原有单图标，不会报错。
- 横屏/竖屏使用“开启图标”表示横屏、“关闭图标”表示竖屏；触摸输入关闭后
  可能无法继续用触摸操作，并会在设备恢复时由 KOReader 自动重新启用。
- 其他没有可靠开关状态的系统操作继续使用单图标。
- 只有开启、关闭两张图标都已设置时才启用动态切换；缺少任意一张时自动
  使用 SimpleUI 原有单图标。
- 在 SimpleUI 快捷设置栏中点击已配置双图标的有状态插件动作后，快捷设置栏
  保持开启并立即重绘；关闭二维码等覆盖窗口后，快捷设置栏仍保留在原处。
- 系统操作不改变 SimpleUI 原有点击流程，是否关闭快捷设置栏以及何时执行均由
  SimpleUI 决定；补丁只负责读取执行后的状态并刷新图标。
- 在双状态图标设置页选取图片后，当前菜单项会立即显示新图片文件名，不需要
  返回上一级再重新进入。

### 擦除渐显翻页动画

支持文字排版以及 PDF、DjVu、CBZ 等固定排版文档。启用补丁并重启后，
详细设置为：

```text
工具
└── 插件增强
    └── 翻页动画
        ├── 擦除渐显翻页动画
        └── 翻页动画设置
            ├── 刷新模式
            │   ├── UI 刷新
            │   └── Fast 刷新
            ├── 竖屏动画帧延迟
            ├── 横屏动画帧延迟
            └── 轻度全局刷新
```

该动画面向 KOReader 2026.07.1 及更新版本的 Linux 墨水屏设备，不支持
Android。

## 依赖

- KOReader。
- SimpleUI 2.1.1、2.5.0 或 2.6.x：扩展模块及 SimpleUI 补丁需要。
- Statistics：阅读统计、阅读洞察等功能需要其数据库。
- FileBrowserPlus 1.2.x：二维码增强需要。

没有安装某个目标插件时，相应组件的加载或启用错误会显示在菜单帮助文本中，
不会阻止其他组件继续加载。

## 安装

这是一个完整 KOReader 插件，不是 KOReader 用户补丁。请勿放入
`koreader/patches/`。

1. 将项目目录命名为 `Plugin_enhancements.koplugin`。
2. 将整个目录复制到 KOReader 的 `plugins/` 目录。
3. 完整重启 KOReader。

```text
koreader/
└── plugins/
    └── Plugin_enhancements.koplugin/
        ├── _meta.lua
        ├── main.lua
        ├── plugin_enhancements_i18n.lua
        ├── locale/
        │   └── zh_CN.po
        ├── modules/
        ├── patches/
        ├── utils/
        ├── README.md
        └── LICENSE
```

不要同时安装原始 `simpleui_ext.koplugin`，否则可能重复注册模块或重复包装
SimpleUI/KOReader 函数。

## 开发约定

扩展模块：

```text
modules/module_<id>.lua
```

补丁：

```text
patches/patch_<id>.lua
```

文件返回表中的 `id` 必须与文件名一致。主入口始终将未知组件的初始状态写为
`false`，不会根据组件自己的 `default_enabled` 自动开启。
